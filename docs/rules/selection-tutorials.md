# Selection Tutorials

Система пошаговых подсказок страницы `/selection`. Каждая карточка оборудования имеет собственный сценарий обучения, запускаемый кнопкой «Подсказки» (?) в шапке карточки.

## Реализация

- Компонент поповера: `resources/js/components/TutorialPopover.jsx`.
- Сценарии и состояния шагов: `resources/js/selection.jsx` (карточки `MixingUnitCard`, `GvsBoilerCard`, `PumpCard`, `ZoneCard` и блок «Котлы»).
- Состояния хранятся в главном компоненте selection: `mixingTutorialStep`, `gvsBoilerTutorialStep`, `pumpTutorialStep`, `zoneTutorialStep`, `boilerTutorialStep` (+ `boilerTutorialNextStep` для ветвления после выбора котла).

## Общее поведение

- Кнопка «Подсказки» переключает обучение: первый клик включает первый шаг сценария, повторный клик или крестик поповера выключают (`step = null`). Активность подсвечивается статусом «Включены/Выключены».
- Поповер всегда размещается над якорным элементом и соединяется с ним SVG-линией с точками на концах.
- `showMask` затемняет страницу, оставляя видимой зону якоря (и опционального `highlightRef`) с отступом 8px.
- `type="blockContent"` дополнительно ставит прозрачный блокиратор над выделенной зоной: клик по нему вызывает анимацию привлечения внимания, а содержимое списка недоступно до нажатия «Далее».
- Шаг закрывается крестиком в любой момент. Повторный запуск сценария всегда начинается с его первого шага.
- Сценарии разных карточек независимы: активное обучение одной карточки не закрывает обучение другой; одновременно активен один шаг на карточку.
- Шаги продвигаются двумя способами: кнопкой-действием внутри поповера либо автоматически, когда пользователь выполняет реальное действие (переключает опцию, добавляет устройство). Автопродвижение срабатывает только если соответствующий шаг сейчас активен.

## Сценарий «Котлы» (`boilerTutorialStep`)

Самый сложный сценарий: `input → select → added-list → connection | add-more → search-more`.

1. `input` — поповер над строкой поиска: «Введите название котла или производителя в это поле». При включении любого шага этого сценария страница плавно скроллится наверх.
2. `select` — включается автоматически, как только у непустого запроса появились результаты поиска. Подсвечивает поле ввода вместе с выпадашкой результатов. Закрывается без перехода, если выпадашку закрыли кликом мимо или Escape.
3. Выбор котла из списка (`addBoilerFromSearch`) переводит сценарий в `added-list` и запоминает следующий шаг в `boilerTutorialNextStep`:
   - `smart` (BUS, `bus_type !== 127`) → далее `connection`;
   - `stupid` (RELAY, `bus_type === 127`) → далее `add-more`.
4. `added-list` — `blockContent` над списком добавленных котлов: «Выбранный котел добавлен…», кнопка «Далее» ведёт на сохранённый следующий шаг.
5. `connection` — поповер над переключателем BUS/RELAY последнего добавленного smart-котла: тип подключения меняют, только если котёл резервный и садится на реле. Переход на `add-more` происходит либо переключением тумблера, либо кнопкой «Оставить без изменений». Для stupid-котлов шаг пропускается.
6. `add-more` — поповер над кнопкой «+ Добавить котёл»: предложение добавить другие котлы. Клик по кнопке открывает выпадашку и переводит сценарий в `search-more`.
7. `search-more` — подсветка поля ввода и выпадашки: выбрать дополнительный котёл из списка или искать по другому запросу. Сценарий завершается закрытием поповера.

## Сценарий «Смесительные узлы» (`mixingTutorialStep`)

Цепочка: `connection → servo → sensor → add → added-list → add-more`.

1. `connection` — над полем «Тип подключения»: проводное или Wi-Fi. Wi-Fi допустим только для совместимого узла 220V с цифровым датчиком (Wi-Fi принудительно выставляет сервопривод 220V и цифровой датчик). Любая смена типа продвигает на `servo`; кнопка «Оставить "По проводу"» выставляет wired и тоже продвигает.
2. `servo` — над полем «Сервопривод»: 220V или 0-10V по маркировке привода. В режиме Wi-Fi доступен только 220V. Смена значения ведёт на `sensor`.
3. `sensor` — над полем «Датчик»; текст зависит от контекста:
   - Wi-Fi: цифровой датчик уже выбран автоматически;
   - привод 0-10V: нужен NTC, цифровой не используется;
   - иначе: объяснение различий цифрового (1-Wire) и NTC.
   Действие выбирает `digital` для Wi-Fi и `ntc` в остальных случаях и ведёт на `add`.
4. `add` — над большой кнопкой добавления; сводка выбранных опций («Выбрано: …»). Если этот вариант уже добавлен, якорем становится список добавленных, текст меняется на «уже добавлен», а кнопка «Показать счётчик» ведёт сразу на `add-more`.
5. `added-list` — `blockContent` над списком; открывается после фактического добавления узла, кнопка «Далее» ведёт на `add-more`.
6. `add-more` — финальный шаг над списком: счётчики «+/−» меняют количество одинаковых узлов, другой вариант добавляется сменой опций выше, модули контроллера подбираются автоматически.

## Сценарий «Бойлеры ГВС» (`gvsBoilerTutorialStep`)

Цепочка: `intro → added-list → count`.

1. `intro` — над кнопкой добавления (если бойлер уже добавлен — над списком): бойлер косвенного нагрева, вместе с ним учитываются насос бойлера и датчик температуры. Если уже добавлен, доступна кнопка «Показать счётчик» → `count`.
2. `added-list` — `blockContent` после добавления, «Далее» ведёт на `count`.
3. `count` — над списком: счётчики «+/−», для каждого бойлера автоматически учитываются насос и датчик температуры.

## Сценарий «Насосы» (`pumpTutorialStep`)

Цепочка: `connection → type → add → added-list → count`.

1. `connection` — над полем «Тип подключения»: по проводу или Wi-Fi (Wi-Fi использует свободный модуль RL6W/RL6SW и требует насос 220V). Смена типа ведёт на `type`.
2. `type` — над полем «Управление»: 220V (релейное) или 0-10V (аналоговое). В режиме Wi-Fi доступен только 220V; текст и подпись действия зависят от режима («Оставить 220V» / «Далее»). Смена значения ведёт на `add`.
3. `add` — над кнопкой добавления со сводкой выбора; если вариант уже в списке — якорь переносится на список и кнопка «Показать счётчик» ведёт на `count`.
4. `added-list` — `blockContent` после добавления, «Далее» ведёт на `count`.
5. `count` — над счётчиком строки: Wi-Fi-насосы система распределяет по свободным каналам Wi-Fi модулей.

## Сценарий «Зоны» (`zoneTutorialStep`)

Цепочка: `connection → add → added-list → count`.

1. `connection` — над полем «Тип подключения»: проводной сервопривод зоны или Wi-Fi (размещается на свободном канале RL6W/RL6SW). Смена типа ведёт на `add`.
2. `add` — над кнопкой добавления со сводкой; если вариант уже добавлен — якорь на список и «Показать счётчик» → `count`.
3. `added-list` — `blockContent` после добавления, «Далее» ведёт на `count`.
4. `count` — над списком: Wi-Fi сервоприводы зон распределяются по свободным каналам Wi-Fi модулей автоматически.

## Инварианты

- Поповер никогда не меняет сторону размещения относительно экрана: он всегда над якорем.
- Обучение не изменяет данные подбора напрямую; данные меняют обычные обработчики (переключатели, добавление устройств), а шаги лишь следуют за ними.
- Автопродвижение шага выполняется только из активного шага; ручные клики мимо сценария не ломают цепочку.
